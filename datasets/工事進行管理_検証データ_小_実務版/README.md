# 工事進行管理 検証データ（小）実務版

「工事進行管理_検証データ_小」と同じ統制・取引・不備を、**実務で受け取る形**に組み替えた版です。証跡の中身は同じで、渡し方（ファイル名・束ね方・版・入れ物）だけを変えています。

**注意：このREADMEと `正解/` フォルダには正解が書かれています。検証対象には渡さないでください。**

## 1. 構成

| フォルダ | 内容 |
|---|---|
| `C_実務版_難/` | A_難版（読みにくい証跡）を組み替えたもの。本番想定 |
| `D_実務版_対照/` | B_対照版（読みやすい証跡）を組み替えたもの。比較用 |
| `正解/` | 正解表_実務版.xlsx、正解.json。検証対象には渡さない |
| `生成スクリプト（参考）/` | 組み替えのプログラム |

個別版（A・B）と合わせると、2つの軸で比べられます。

| | 個別のファイル | 実務の渡し方 |
|---|---|---|
| 読みにくい | A_難版 | C_実務版_難 |
| 読みやすい | B_対照版 | D_実務版_対照 |

- A と C、B と D の差が「渡し方に起因する誤り」です。C と D の差が「読み取りに起因する誤り」です。

## 2. 入力の形

- `手続一覧.xlsx`：リスクと統制・手続・サンプル。個別版にあった証跡のフォルダ・ファイル名の手がかりの列はありません。
- `共通資料/`：規程・基準、データ
- `受領資料/`：提出元・提出日ごとのフォルダに 11 ファイル。個別版の証跡はすべてこの中に入っています。
- 拡張子：pdf 8、xlsx 2、csv 1、tif 1、docx 1、zip 1、eml 1（ZIP・メールの中のファイルを除く）

## 3. 渡し方の変化

| 変化 | 対象 | 内容 | 正解への影響 |
|---|---|---|---|
| ファイル名 | 受領資料の全ファイル | スキャナ・複合機の既定名、日時だけの名前、「資料1」「Book1」など。名前から中身が分からない | なし |
| フォルダ | 受領資料 | 手続別ではなく、提出元・提出日ごとのフォルダ。1つの手続の証跡が複数のフォルダ・ファイルに分かれる | なし |
| 束ね（複数の証跡を1ファイルに） | doc20260410110542.pdf、IMG_20260331.pdf、SCAN_20260410_0002.pdf、SCAN_20260410_0003.pdf、SCAN_20260413_0001.pdf | 複数のサンプル・文書の種類が1つのPDFに入っている。順不同のものがある | なし |
| 向き・白紙・送付状・無関係な資料 | doc20260410110542.pdf、SCAN_20260410_0002.pdf | 証跡ではないページを見分け、向きの違うページも読む | なし |
| 版違い（正しい版がある） | SCAN_20260413_0001.pdf、kouji_kitei_2022.pdf | 承認済みの最終版・現行版を選べるか。古い版・案で判定すると誤る | なし（正しい版を使えば同じ） |
| 大量ページ | IMG_20260331.pdf | 長い資料から該当の箇所を探す | なし |
| Officeへの貼り付け | Book1.xlsx、新規 Microsoft Word 文書.docx | セルや本文の文字ではなく、埋め込まれた画像を取り出して読む | なし |
| 拡張子・入れ物 | fax_20260410.tif、契約関係.zip、RE_ 【内部監査】査定書の件.eml、genka_meisai_2025.csv | 入れ物（TIFF・ZIP・メールの添付・CSV）を開いて中の証跡を取り出す | なし |
| 最終版がない（作成中の版のみ） | SCAN_20260410_0003.pdf | 「作成中（承認前）」の版しか提出されていない | C04 S4 が「判断できない」に変わる |
| ページの欠落 | doc20260410110542.pdf | 綴りや複数ページの資料から必要なページが抜けている | C02 K-2501 が「判断できない」に変わる |
| 開けないファイル | 添付ファイル.pdf | パスワード付きのPDF。パスワードは提供されていない | C01 K-2504 が「判断できない」に変わる；C05 K-2504 が「判断できない」に変わる |

## 4. 正解

| 手続 | 種類 | C_実務版_難 | D_実務版_対照 | 参考：A | 参考：B | 個別版との違い |
|---|---|---|---|---|---|---|
| C01 | 再計算 | 不備あり | 不備あり | 不備あり | 不備あり | 同じ |
| C02 | 図面（工程表）と報告の突合 | 不備あり | 不備あり | 不備あり | 不備あり | 同じ |
| C03 | 基準への当てはめ | 不備なし | 不備なし | 不備なし | 不備なし | 同じ |
| C04 | 照合 | 判断できない | 判断できない | 判断できない | 不備なし | 変わる |
| C05 | 契約書類の読解と突合 | 判断できない | 判断できない | 不備なし | 不備なし | 変わる |

- 手続単位：C は 不備なし 1／不備あり 2／判断できない 2、D は 1／2／2
- 判定の単位は 16（個別版と同じ）。渡し方で正解が変わるのは 4 単位（C01 K-2504、C02 K-2501、C04 S4、C05 K-2504）で、いずれも「判断できない」になります。
- 版違いのある単位（C01 K-2507、C03 K-2504）は、承認済みの最終版・現行版で判定すれば個別版と同じ正解です。

## 5. 使い方

1. `C_実務版_難/`（または `D_実務版_対照/`）をフォルダごと検証対象に入力する。
2. `正解/正解表_実務版.xlsx` の「単位別の正解」と突き合わせる。
3. 誤った単位は「証跡の所在（実務版）」と「所在の対応表」で、どのファイルの何ページ目を見るべきだったかを確かめる。原因を「探せなかった／読めなかった／判断を誤った」に分けられます。

## 6. 前提と制約

- 同じ文書に複数の版がある場合、承認済みの最終版・現行版を証跡とします。この前提は手続一覧には書いていません（検証対象が判断する想定）。
- 「作成中の版しかない」「ページが抜けている」「開けない」は、不備ではなく「判断できない」を正解にしています。追加の提出を求めるべき場面だからです。
- 版どうしが食い違い、どちらが正しいか決められない、という型は入れていません。正解が一意に決まらないためです。
- Word・Excel に貼った画像は、元の証跡を画像にしたものです。
- K-2504 の現場写真（3/30 電気）は、3月の写真台帳の中の1ページとして入れています。ほかの写真は合成で、3/30 までの電気工事の進み具合（10スパン中1〜2スパン）と矛盾しない内容です。
- 変更覚書が開けないことで、2つの単位（C01 K-2504、C05 K-2504）が「判断できない」になります。工事原価明細は Excel ではなく CSV（Shift_JIS）です。
- メールアドレス・社名・人名はすべて架空です。
