# 実地棚卸 検証データ（小）実務版

「実地棚卸_検証データ_小」と同じ統制・取引・不備を、**実務で受け取る形**に組み替えた版です。証跡の中身は同じで、渡し方（ファイル名・束ね方・版・入れ物）だけを変えています。

**注意：このREADMEと `正解/` フォルダには正解が書かれています。検証対象には渡さないでください。**

## 1. 構成

| フォルダ | 内容 |
|---|---|
| `C_実務版_難/` | A_難版（読みにくい証跡）を組み替えたもの。本番想定 |
| `D_実務版_対照/` | B_対照版（読みやすい証跡）を組み替えたもの。比較用 |
| `正解/` | 正解表_実務版.xlsx、正解.json。検証対象には渡さない |
| `生成スクリプト（参考）/` | 組み替えのプログラム |

個別版（A・B）と合わせると、2つの軸で比べられます。

| | 個別のファイル | 実務の渡し方 |
|---|---|---|
| 読みにくい | A_難版 | C_実務版_難 |
| 読みやすい | B_対照版 | D_実務版_対照 |

- A と C、B と D の差が「渡し方に起因する誤り」です。C と D の差が「読み取りに起因する誤り」です。

## 2. 入力の形

- `手続一覧.xlsx`：リスクと統制・手続・サンプル。個別版にあった証跡のフォルダ・ファイル名の手がかりの列はありません。
- `共通資料/`：規程・基準、データ
- `受領資料/`：提出元・提出日ごとのフォルダに 8 ファイル。個別版の証跡はすべてこの中に入っています。
- 拡張子：pdf 7、xlsx 2、csv 1、zip 1、tif 1、eml 1、docx 1（ZIP・メールの中のファイルを除く）

## 3. 渡し方の変化

| 変化 | 対象 | 内容 | 正解への影響 |
|---|---|---|---|
| ファイル名 | 受領資料の全ファイル | スキャナ・複合機の既定名、日時だけの名前、「資料1」「Book1」など。名前から中身が分からない | なし |
| フォルダ | 受領資料 | 手続別ではなく、提出元・提出日ごとのフォルダ。1つの手続の証跡が複数のフォルダ・ファイルに分かれる | なし |
| 束ね（複数の証跡を1ファイルに） | SCAN_20260408_0001.pdf、SCAN_20260408_0002.pdf | 複数のサンプル・文書の種類が1つのPDFに入っている。順不同のものがある | なし |
| 向き・白紙・送付状・無関係な資料 | SCAN_20260408_0001.pdf、SCAN_20260408_0002.pdf | 証跡ではないページを見分け、向きの違うページも読む | なし |
| 版違い（正しい版がある） | SCAN_20260408_0002.pdf、youryou_2024.pdf、物-012 - コピー.pdf | 承認済みの最終版・現行版を選べるか。古い版・案で判定すると誤る | なし（正しい版を使えば同じ） |
| 大量ページ | Z0310_20260408091533.pdf | 長い資料から該当の箇所を探す | なし |
| Officeへの貼り付け | Book1.xlsx、無題のドキュメント.docx | セルや本文の文字ではなく、埋め込まれた画像を取り出して読む | なし |
| 拡張子・入れ物 | fax_20260408.tif、物流課.zip、RE_ 棚卸資料の送付漏れ.eml、zaiko_20260331.csv | 入れ物（TIFF・ZIP・メールの添付・CSV）を開いて中の証跡を取り出す | なし |
| 最終版がない（作成中の版のみ） | 物流課.zip | 「作成中（承認前）」の版しか提出されていない | T04 OR-P20-100 が「判断できない」に変わる |
| ページの欠落 | SCAN_20260408_0001.pdf | 綴りや複数ページの資料から必要なページが抜けている | T01 連番（No.001〜024） が「判断できない」に変わる；T02 その他の区画 が「判断できない」に変わる；T03 No.018 が「判断できない」に変わる |

## 4. 正解

| 手続 | 種類 | C_実務版_難 | D_実務版_対照 | 参考：A | 参考：B | 個別版との違い |
|---|---|---|---|---|---|---|
| T01 | 連番の検査（全件） | 判断できない | 判断できない | 不備なし | 不備なし | 変わる |
| T02 | 図面と記録の突合（網羅性） | 不備あり | 不備あり | 不備あり | 不備あり | 同じ |
| T03 | 再実施（手書きの読み取り） | 不備あり | 不備あり | 不備あり | 不備あり | 同じ |
| T04 | 再計算・基準への当てはめ | 判断できない | 判断できない | 判断できない | 不備なし | 変わる |
| T05 | 写真・立会記録との突合 | 不備なし | 不備なし | 不備なし | 不備なし | 同じ |

- 手続単位：C は 不備なし 1／不備あり 2／判断できない 2、D は 1／2／2
- 判定の単位は 20（個別版と同じ）。渡し方で正解が変わるのは 4 単位（T01 連番（No.001〜024）、T02 その他の区画、T03 No.018、T04 OR-P20-100）で、いずれも「判断できない」になります。
- 版違いのある単位（T02 C-4（仮置場）、T03 No.006、T04 AC-20-50）は、承認済みの最終版・現行版で判定すれば個別版と同じ正解です。

## 5. 使い方

1. `C_実務版_難/`（または `D_実務版_対照/`）をフォルダごと検証対象に入力する。
2. `正解/正解表_実務版.xlsx` の「単位別の正解」と突き合わせる。
3. 誤った単位は「証跡の所在（実務版）」と「所在の対応表」で、どのファイルの何ページ目を見るべきだったかを確かめる。原因を「探せなかった／読めなかった／判断を誤った」に分けられます。

## 6. 前提と制約

- 同じ文書に複数の版がある場合、承認済みの最終版・現行版を証跡とします。この前提は手続一覧には書いていません（検証対象が判断する想定）。
- 「作成中の版しかない」「ページが抜けている」「開けない」は、不備ではなく「判断できない」を正解にしています。追加の提出を求めるべき場面だからです。
- 版どうしが食い違い、どちらが正しいか決められない、という型は入れていません。正解が一意に決まらないためです。
- Word・Excel に貼った画像は、元の証跡を画像にしたものです。
- 棚卸原票の1枚（No.017〜020）の欠落により、3つの単位（T01 連番、T02 その他の区画、T03 No.018）が「判断できない」になります。このセットには、開けないファイルは入れていません（1つの文書に多くの単位が依存するため）。
- 受払明細（3月）は、帳簿在庫一覧の帳簿数量の内訳に当たる参考資料です。帳簿在庫一覧は Excel ではなく CSV（Shift_JIS）です。
- メールアドレス・社名・人名はすべて架空です。
