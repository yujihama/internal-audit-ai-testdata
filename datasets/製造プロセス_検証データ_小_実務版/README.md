# 製造プロセス 検証データ（小）実務版

「製造プロセス_検証データ_小」と同じ統制・取引・不備を、**実務で受け取る形**に組み替えた版です。証跡の中身は同じで、渡し方（ファイル名・束ね方・版・入れ物）だけを変えています。

**注意：このREADMEと `正解/` フォルダには正解が書かれています。検証対象には渡さないでください。**

## 1. 構成

| フォルダ | 内容 |
|---|---|
| `C_実務版_難/` | A_難版（読みにくい証跡）を組み替えたもの。本番想定 |
| `D_実務版_対照/` | B_対照版（読みやすい証跡）を組み替えたもの。比較用 |
| `正解/` | 正解表_実務版.xlsx、正解.json。検証対象には渡さない |
| `生成スクリプト（参考）/` | 組み替えのプログラム |

個別版（A・B）と合わせると、2つの軸で比べられます。

| | 個別のファイル | 実務の渡し方 |
|---|---|---|
| 読みにくい | A_難版 | C_実務版_難 |
| 読みやすい | B_対照版 | D_実務版_対照 |

- A と C、B と D の差が「渡し方に起因する誤り」です。C と D の差が「読み取りに起因する誤り」です。

## 2. 入力の形

- `手続一覧.xlsx`：リスクと統制・手続・サンプル。個別版にあった証跡のフォルダ・ファイル名の手がかりの列はありません。
- `共通資料/`：規程・基準、データ
- `受領資料/`：提出元・提出日ごとのフォルダに 11 ファイル。個別版の証跡はすべてこの中に入っています。
- 拡張子：pdf 10、xlsx 2、eml 1、tif 1、docx 1、zip 1（ZIP・メールの中のファイルを除く）

## 3. 渡し方の変化

| 変化 | 対象 | 内容 | 正解への影響 |
|---|---|---|---|
| ファイル名 | 受領資料の全ファイル | スキャナ・複合機の既定名、日時だけの名前、「資料1」「Book1」など。名前から中身が分からない | なし |
| フォルダ | 受領資料 | 手続別ではなく、提出元・提出日ごとのフォルダ。1つの手続の証跡が複数のフォルダ・ファイルに分かれる | なし |
| 束ね（複数の証跡を1ファイルに） | SCAN_20260408_0001.pdf、doc20260409101533.pdf、doc20260409102210.pdf、SCAN0012.pdf、20260410113025.pdf | 複数のサンプル・文書の種類が1つのPDFに入っている。順不同のものがある | なし |
| 向き・白紙・送付状・無関係な資料 | SCAN_20260408_0001.pdf、doc20260409101533.pdf、doc20260409102210.pdf、SCAN0012.pdf | 証跡ではないページを見分け、向きの違うページも読む | なし |
| 版違い（正しい版がある） | doc20260409101533.pdf、K02.pdf | 承認済みの最終版・現行版を選べるか。古い版・案で判定すると誤る | なし（正しい版を使えば同じ） |
| 大量ページ | B0110_20260408101233.pdf | 長い資料から該当の箇所を探す | なし |
| Officeへの貼り付け | 新規 Microsoft Word 文書.docx、Book1.xlsx | セルや本文の文字ではなく、埋め込まれた画像を取り出して読む | なし |
| 拡張子・入れ物 | スキャン_0003.tif、製造課.zip、RE_ 【内部監査】資料のご依頼.eml | 入れ物（TIFF・ZIP・メールの添付・CSV）を開いて中の証跡を取り出す | なし |
| 最終版がない（作成中の版のみ） | 20260410113025.pdf | 「作成中（承認前）」の版しか提出されていない | F03 MO-2511-006 が「判断できない」に変わる |
| ページの欠落 | SCAN0012.pdf | 綴りや複数ページの資料から必要なページが抜けている | F02 S1 が「判断できない」に変わる |
| 開けないファイル | 添付1.pdf | パスワード付きのPDF。パスワードは提供されていない | F05 M-02（2026年1月） が「判断できない」に変わる |

## 4. 正解

| 手続 | 種類 | C_実務版_難 | D_実務版_対照 | 参考：A | 参考：B | 個別版との違い |
|---|---|---|---|---|---|---|
| F01 | 再計算（単位の換算を含む） | 不備あり | 不備あり | 不備あり | 不備あり | 同じ |
| F02 | 測定値と規格の突合 | 不備あり | 不備あり | 不備あり | 不備あり | 同じ |
| F03 | 手書き記録の再集計 | 判断できない | 判断できない | 判断できない | 不備なし | 変わる |
| F04 | 帳票間の整合 | 不備なし | 不備なし | 不備なし | 不備なし | 同じ |
| F05 | 点検記録の検査 | 判断できない | 判断できない | 不備なし | 不備なし | 変わる |

- 手続単位：C は 不備なし 1／不備あり 2／判断できない 2、D は 1／2／2
- 判定の単位は 16（個別版と同じ）。渡し方で正解が変わるのは 3 単位（F02 S1、F03 MO-2511-006、F05 M-02（2026年1月））で、いずれも「判断できない」になります。
- 版違いのある単位（F01 S3、F02 S3）は、承認済みの最終版・現行版で判定すれば個別版と同じ正解です。

## 5. 使い方

1. `C_実務版_難/`（または `D_実務版_対照/`）をフォルダごと検証対象に入力する。
2. `正解/正解表_実務版.xlsx` の「単位別の正解」と突き合わせる。
3. 誤った単位は「証跡の所在（実務版）」と「所在の対応表」で、どのファイルの何ページ目を見るべきだったかを確かめる。原因を「探せなかった／読めなかった／判断を誤った」に分けられます。

## 6. 前提と制約

- 同じ文書に複数の版がある場合、承認済みの最終版・現行版を証跡とします。この前提は手続一覧には書いていません（検証対象が判断する想定）。
- 「作成中の版しかない」「ページが抜けている」「開けない」は、不備ではなく「判断できない」を正解にしています。追加の提出を求めるべき場面だからです。
- 版どうしが食い違い、どちらが正しいか決められない、という型は入れていません。正解が一意に決まらないためです。
- Word・Excel に貼った画像は、元の証跡を画像にしたものです。
- 部品表は、全製品の一覧（システムからの出力）に差し替えています。サンプルの3品番の内容は個別版の部品表と同じです。
- メールアドレス・社名・人名はすべて架空です。
